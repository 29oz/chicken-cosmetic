# Chicken Ball

A [Ballest](https://store.steampowered.com/app/3339810/Ballest_of_Them_All/) cosmetic plugin that puts the Crossy Road chicken inside your ball.

![Preview](chicken_bubble_preview.png)

## Features

- Voxel chicken model with walk and idle animations
- Chicken faces the direction the ball rolls
- Walk speed scales with ball speed, idles when still

## Dependencies

- [cosmetic-kit](https://github.com/AnythingGoes-ballest/ballest-cosmetic-kit) (Ballest plugin)
